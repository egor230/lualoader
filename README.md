# LUALOADER для GTA Vice City

![LUALOADER для GTA Vice City](Ретро-коллаж%20GTAVC%20LUALOADER.png)

**LUALOADER** — это Lua-скриптовый движок для **GTA Vice City**, по идее похожий на **MoonLoader** (для GTA SA), но сделанный специально под Vice City. Он позволяет писать скрипты и целые миссии на языке **Lua** прямо для игры — в стиле CLEO, но обычно **примерно в 3 раза короче и удобнее**: меньше шаблонного кода, понятные функции, быстрая проверка идей и простая работа с игровыми сущностями.

## Что это даёт

- **Скрипты на Lua** — автоматизация, читы/утилиты, геймплейные моды, эксперименты с миром, транспортом, педами и объектами.
- **Миссии на Lua** — можно писать полноценные миссионные сценарии (маркеры, катсцены/логика, цели, условия победы/провала, очистка сцены).
- **Стиль как в CLEO, но компактнее** — привычные действия (создать педа/машину/объект, выдать оружие, телепортировать, проверить условия, показать текст и т.д.) выражаются коротким Lua-кодом.
- **Большой набор игровых функций** — работа с игроком/педами, транспортом, объектами, маркерами/блипами, оружием, погодой, розыском, камерой, проверками состояний и т.п.
- **Горячая перезагрузка скриптов** — правки можно быстро проверять без полного цикла пересборки (в зависимости от сценария/скрипта).

## Как устроены скрипты

Скрипты — это обычные `.lua` файлы в папке `lualoader/`. Типовой скрипт содержит функцию `main()` с игровым циклом:

```lua
require("lualoader/mod")

function main()
  while true do
    wait(0)
    local player = findplayer()

    -- ваша логика здесь
    -- пример: реакция на клавишу, создание/проверка сущностей, вывод сообщений и т.д.
  end
end
```

- `main()` — точка входа скрипта.
- `while true do ... wait(...) end` — основной цикл; `wait()` отдаёт время игре/загрузчику (без зависания).
- Через API можно получать игрока, создавать/удалять педов, машины, объекты, ставить маркеры, проверять условия и т.д.

## Как пишутся миссии (кратко)

Миссии тоже пишутся на Lua, обычно по такой схеме:

1. **Ожидание старта** — в цикле проверяется условие запуска (например, игрок подошёл к маркеру миссии через `Star_mission_marker(...)`).
2. **Инициализация** — выставляются начальные переменные/состояния, выдаётся оружие/одежда, создаются блайпы, маркеры, сферы, запускаются анимации/настройки.
3. **Основной цикл миссии** — `while true == Getflagmission() do wait() ... end`, внутри которого по шагам (`step`) выполняется логика: подъехать в точку, запустить сцену, заспавнить актёров/транспорт, обрабатывать события.
4. **Проверки целей и событий** — отслеживаются условия (жив/мёртв, уничтожен транспорт, достигнута точка, надета одежда, сработал триггер и т.п.) и меняется этап миссии.
5. **Завершение** — при успехе вызывается завершение миссии (например, `miss(...)`), при провале/выходе — выполняется очистка (удаление блайпов/маркеров/сфер, сброс интенсивности, удаление созданных сущностей, закрытие ворот/объектов и т.д.).

Такой подход позволяет писать миссии намного короче и нагляднее, чем аналогичная логика в низкоуровневых скриптах.

## Что есть в репозитории

- `lualoader/` — скрипты, модули и ресурсы загрузчика.
- `lualoader-src/` — исходный код плагина/загрузчика.
- `lualoader.asi` — собранный плагин.
- `Source missions/` — исходники/материалы миссий.

## Установка (в общих чертах)

1. Скопируйте `lualoader.asi` в папку с игрой GTA Vice City (где установлен ASI-загрузчик).
2. Скопируйте папку `lualoader/` в папку с игрой.
3. Запустите игру — скрипты из `lualoader/` будут подхвачены загрузчиком.

> Точные зависимости/сборка могут отличаться в зависимости от вашей конфигурации игры и набора плагинов.

## Для разработчиков

- Исходники: `lualoader-src/`
- Сборка: см. `lualoader-src/build.sh` (и сопутствующие файлы проекта)
- Lua API обширный и ориентирован на задачи в стиле CLEO/скриптинга GTA VC (игрок, педы, транспорт, объекты, проверки, миссионная логика и др.)
